
# Titanic Dataset - Week 1 Data Cleaning

## Project Overview
This project focuses on cleaning and preprocessing the Titanic dataset using Python.

## Tasks Completed
- Identified and handled missing values.
- Filled missing Age values using the median.
- Filled missing Embarked values using the mode.
- Removed the Cabin column due to excessive missing values.
- Encoded Sex and Embarked columns into numerical values.
- Visualized the Age distribution using a histogram.
- Verified the cleaned dataset.
- Exported the cleaned dataset as a new CSV file.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files Included
- `Titanic_Week1_Data_Cleaning.ipynb` – Notebook containing the code, data cleaning steps, and visualization.
- `Titanic_cleaned.csv` – Cleaned dataset.

## Visualization
The Age distribution of Titanic passengers was visualized using a histogram with Seaborn and Matplotlib.

## Outcome
The dataset was cleaned, categorical columns were encoded, missing values were handled, and the cleaned data was exported for further analysis.
